About DVC: https://dvc.org/doc/user-guide
Data Version Control (DVC) သည် အခမဲ့နှင့် open-source tool တစ်ခုဖြစ်ပြီး၊ data management၊ ML pipeline automation နှင့် experiment management တို့အတွက် အသုံးပြုပါတယ်။ ၎င်းသည် data science နှင့် machine learning teams များအား large datasets များကို စီမံခန့်ခွဲရန်၊ projects များကို reproducible ဖြစ်စေရန်နှင့် ပိုမိုကောင်းမွန်စွာ collaboration လုပ်နိုင်ရန် ကူညီပေးပါတယ်။

DVC သည် သင့်အသင်းမှ ရင်းနှီးပြီးသား software engineering toolset များ (Git, IDE, CI/CD, cloud storage စသည်) ကို အသုံးပြုပါတယ်။ ၎င်း၏ ဒီဇိုင်းသည် အောက်ပါ principles များကို လိုက်နာပါတယ်:

Codification: သင့် ML project ၏ မည်သည့်အပိုင်းကိုမဆို (data နှင့် model versions, ML pipelines နှင့် experiments) human-readable metafiles များဖြင့် သတ်မှတ်ပါတယ်။ ၎င်းသည် best practices နှင့် established engineering toolsets များကို အသုံးပြုနိုင်စေပြီး၊ data science နှင့် ကွာဟမှုကို လျှော့ချပေးပါတယ်။

Versioning: Git (သို့မဟုတ် မည်သည့် SCM ကိုမဆို) ကို အသုံးပြုပြီး သင့် ML project တစ်ခုလုံးကို versioning နှင့် sharing လုပ်ပါတယ်။ ၎င်းတွင် source code နှင့် configuration၊ parameters နှင့် metrics၊ data assets နှင့် processes တို့ ပါဝင်ပြီး၊ DVC metafiles များကို (placeholders အဖြစ်) commit လုပ်ပါ။

Secure collaboration: သင့် project ၏ မည်သည့်အပိုင်းကိုမဆို ဝင်ရောက်ခွင့်ကို ထိန်းချုပ်ပြီး၊ သင်ရွေးချယ်ထားသော လူများနှင့် အသင်းများနှင့် မျှဝေnaingပါတယ်။
