For the first time user:<br>
git config --global user.name “Your Name” Set the name that will be attached to your commits and tags.<br>
git config --global user.email “you@example.com”<br>
Set the e-mail address that will be attached to your commits and tags.<br>
References: GitLab https://about.gitlab.com/images/press/git-cheat-sheet.pdf


Working a project
Clone a repository: git clone <repo_name><br>
Make some changes to the README file<br>
Add file to staging area: git add <filename><br>
Commit to Local Repository: git commit -m "<message>"<br>
Push to Remote Repository: git push origin <branch_name><br>
Changes something in the readme file from the GitHub Repo<br>
Pull from the Local Working Directory: git pull origin <branch_name><br>
View Logs: git log<br>

Creating a Branch:<br>
Creating a Branch from GitHub:<br>
Go to Remote Repo and create a branch<br>

Creating a Branch Using Command Lines:<br>
List all local branches in repository. With -a: show all branches (with remote): <br>
Create new branch, referencing the current HEAD: git branch [branch_name]
